# Daria Ivanova

Talent Acquisition specialist focused on bringing AI into the hiring workflow: sourcing, candidate research, recruiting automation.

**Stack:** AI-assisted sourcing · recruiting automation · Huntflow ATS · Claude Code skills

### Recent work
- **[AI-in-TA Telegram bot](https://github.com/Da6ka/ai-in-ta-telegram-bot)**: a daily briefing of AI-in-recruitment news, generated and delivered automatically
- **[huntflow-tools](https://github.com/Da6ka/huntflow-tools)**: unofficial CLI helpers and Claude Code skills for the recruiting pipeline. Search candidates, create and update vacancies, move candidates between stages, add applicants from a CV, process applications from a website form, and fill gaps in Huntflow's public API, like reordering pipeline stages or attaching a CV to an existing candidate
- **tech-sourcing-skill**: a Claude Code skill that turns a job description into a candidate persona, finds matching LinkedIn & other social media profiles, scores them, and drafts personalized outreach in one pass
- **outreach-memory**: semantic search over my past cold outreach. I describe a role and get back the letters I sent for similar ones, replied-to first. An English query finds the Russian letter. It runs on my laptop, so candidate messages stay there
- **telegram-reading-kit**: lets Claude Code read my own Telegram account in plain language ("what did I get today?", "find messages about this role"). A Node CLI helper plus Telethon scripts, with tests and CI. It reads freely and sends only on my explicit word, and treats everything it reads as data, not instructions
- **Telegram → VK crosspost** *(paused)*: a webhook relay that mirrors a construction charity's Telegram channel into its VK community chat within a minute of publishing, so volunteers on either platform see the same updates
