### Recent work
- **[AI-in-TA Telegram bot](https://github.com/Da6ka/ai-in-ta-telegram-bot)**: a daily briefing of AI-in-recruitment news, generated and delivered automatically
- **[huntflow-tools](https://github.com/Da6ka/huntflow-tools)**: unofficial CLI helpers and Claude Code skills for the recruiting pipeline. Search candidates, move them between stages, add applicants from a CV, and cover gaps in Huntflow's public API like reordering stages.
- **tech-sourcing-skill** *(private repo)*: a Claude Code skill that turns a job description into a candidate persona, finds matching LinkedIn & other social media profiles, scores them, and drafts personalized outreach in one pass
- **outreach-memory** *(private repo)*: semantic search over my past cold outreach. I describe a role and get back the letters I sent for similar ones, replied-to first. An English query finds the Russian letter. It runs on my laptop, so candidate messages stay there
- **telegram-reading-kit** *(private repo)*: lets Claude Code read my own Telegram account in plain language ("what did I get today?", "find messages about this role"). A Node CLI helper plus Telethon scripts, with tests and CI. It reads freely and sends only on my explicit word, and treats everything it reads as data, not instructions
